「疑わしいファイル拡張子をブロックする」オプションは、組織用に設定したデフォルトのリストを使用します。作成したlink:task-file-extensions.html["カスタムリストを使用する"]には、鉛筆アイコンを選択します。

+ ONTAPでブロックするファイル拡張子のリストを設定している場合、*ONTAPリストをRansomware Resilienceリストに置き換える*を選択することで、それらのリストを上書きできます。次に、SVMで*ブロックされたリストを除くすべてのファイル拡張子を許可する*か、*許可されたリストを除くすべてのファイル拡張子をブロックする*のどちらを実行するかを選択します。次に、ドロップダウンメニューからリストを選択します。ワークロード上のすべてのストレージVM（SVM）がそのリストを使用します。後で、ワークロード上の異なるSVMに異なるリストを適用することもできます。
